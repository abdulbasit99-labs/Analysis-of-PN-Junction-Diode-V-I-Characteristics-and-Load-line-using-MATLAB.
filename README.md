# Analysis-of-PN-Junction-Diode-V-I-Characteristics-and-Load-line-using-MATLAB.
The main objective of this project to analyze the V-I characteristics of PN junction diode. How diode works in forward biased and current voltage exponentially relationship. This project also demonstrate the Q point (Quiescent point) on the Load line. This project also tells about behaviour of diode on different parameters.
# IoT-Based Smart Plant Health & Soil Monitoring System

## Objective
To monitor soil moisture, temperature, humidity & light intensity in real-time and automate irrigation to reduce water wastage.

## Main Concept
ESP32 + Soil Moisture + DHT22 + BH1750 sensors. Calculates Plant Health Index (0-100 score). Auto ON/OFF water pump via relay when moisture < 35%. OLED display + Wi-Fi IoT ready.

## Hardware Used
- ESP32 Dev Board
- Soil Moisture Sensor, DHT22, BH1750, OLED, Relay, Water Pump

## Software Used
- Arduino IDE, DHT & BH1750 & Adafruit Libraries

## How to Run
1. Connect sensors as per circuit diagram
2. Open `code/esp32_plant_monitoring.ino` in Arduino IDE
3. Install libraries
4. Upload to ESP32

## Result
Auto irrigation + live OLED data + Plant Health Index calculation.
